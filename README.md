# gitunia.github.io

Landing page for [Gitunia](https://github.com/Aleksanderis/Gitunia). Static files, no build step: `index.html`, `assets/`, `media/`.

Preview: `python3 -m http.server 8000` and open http://localhost:8000.

The Features list is a copy of the one in the main README; update both. `assets/` and `media/demo.gif` are copies from the main repo's `docs/assets` and `docs/media`.
